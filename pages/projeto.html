Projeto Final — Linux na Prática

Três cenários reais. Use o terminal para resolver cada um. Sem consultar — tente do seu jeito primeiro.

🎯 3 cenários 💻 Terminal interativo ✓ Validação automática

Cenário 1 — Processo Fantasma

Iniciante+

Um processo está consumindo 99% da CPU. Identifique-o com ps aux, anote o PID e encerre com kill -9 <PID>. Confirme com ps aux novamente.

usuario@linuxwiki: ~

Cenário 2 — Script Sem Permissão

Iniciante+

Seu script deploy.sh não executa. Use ls -la para ver as permissões, depois chmod 755 deploy.sh para torná-lo executável e finalmente ./deploy.sh para executá-lo.

usuario@linuxwiki: ~

Cenário 3 — Disco Cheio

Intermediário

O sistema reporta disco cheio. Use df -h para ver o uso geral, depois du -sh * no home para identificar o diretório culpado (o diretório downloads está com 48 GB!), e finalmente rm -r downloads para liberar espaço.
