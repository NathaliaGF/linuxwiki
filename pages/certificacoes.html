Por que certificações importam (e quando não importam)

📖 Explicação

Certificações servem a propósitos específicos — entender quando elas ajudam e quando não são necessárias evita desperdício de tempo e dinheiro.

  • Sinalizam conhecimento de forma verificável para recrutadores e clientes que não têm como avaliar sua experiência diretamente.
  • Estruturam o aprendizado — o currículo da certificação cobre áreas que você evitaria naturalmente, fechando lacunas.
  • Requisito em alguns setores: consultorias, órgãos governamentais e grandes corporações frequentemente exigem certificações como pré-requisito formal.
💡 Analogia — Quando NÃO certificar

Para empresas de produto e startups, experiência prática demonstrável (GitHub, projetos reais, contribuições open-source) costuma pesar mais que certificações. Uma RHCSA pode ser mais impressionante que um diploma genérico, mas um projeto real em produção vencendo ambos. Invista em prática primeiro — a experiência é o que permite passar nas provas práticas.

ℹ️ Saiba mais

Custo aproximado (2025): LPIC-1 ~$200 por exame (são 2 exames = ~$400 total), RHCSA ~$400, CompTIA Linux+ ~$370. Os preços variam por região — o site Pearson VUE e os sites oficiais têm valores atualizados. Vouchers de desconto frequentemente disponíveis em treinamentos oficiais.

LPIC-1: Linux Professional Institute

📖 Explicação

O LPIC-1 (Linux Professional Institute Certification Level 1) é uma certificação vendor-neutral — os conceitos cobertos funcionam em qualquer distribuição Linux.

São dois exames separados, ambos necessários para obter a certificação:

  • Exame 101-500: arquitetura do sistema, instalação e configuração de Linux, gerenciamento de pacotes (apt, rpm), comandos GNU/Unix, sistema de arquivos.
  • Exame 102-500: shell e scripts, interfaces gráficas, tarefas administrativas (usuários, grupos, automação via cron), serviços essenciais, fundamentos de redes, segurança básica.

Validade: 5 anos. Formato: múltipla escolha e fill-in-the-blank. Bom ponto de entrada para quem quer demonstrar conhecimento formal de forma independente de distro.

⚡ O que você precisa guardar
  • Dois exames: 101-500 + 102-500
  • Vendor-neutral — vale para qualquer distro
  • Formato teórico (múltipla escolha)
  • Validade de 5 anos
  • Boa porta de entrada para o mercado

CompTIA Linux+

📖 Explicação

A CompTIA Linux+ (exame XK0-005) é um único exame com foco mais aplicado do que teórico. Se diferencia das outras certificações por cobrir tópicos modernos:

  • Gerenciamento de sistemas (40%): administração geral, systemd, storage.
  • Segurança (21%): hardening, SELinux/AppArmor, criptografia, auditing.
  • Scripting e automação (19%): bash scripting, conceitos de automação.
  • Troubleshooting (20%): diagnóstico e resolução de problemas.

Reconhecida pelo DoD dos EUA (Departamento de Defesa) para cargos de segurança — isso a torna requisito em muitos contratos governamentais americanos. Vendor-neutral.

ℹ️ Saiba mais

Não há pré-requisito formal, mas a CompTIA recomenda 12 meses de experiência prática. A CompTIA Linux+ é parte da linha "core" de certificações junto com A+, Network+ e Security+. Se você planeja seguir carreira em segurança ou infraestrutura com foco em compliance, a combinação Linux+ + Security+ é especialmente valorizada.

RHCSA: Red Hat Certified System Administrator

📖 Explicação

A RHCSA é considerada uma das certificações Linux mais valiosas no mercado por uma razão simples: é 100% prática. Você administra sistemas RHEL reais em um ambiente de laboratório por 2-3 horas, sem alternativas de múltipla escolha para adivinhar.

Tópicos cobertos:

  • Gerenciamento de arquivos, usuários e grupos
  • Gerenciamento de processos e serviços com systemd
  • Configuração básica de rede
  • Storage com LVM (Logical Volume Manager)
  • SELinux: contextos, booleans, troubleshooting
  • Containers básicos com podman

Validade: 3 anos. Focada em RHEL/CentOS Stream/Rocky Linux.

⚠️ Erros comuns
  • Estudar teoria sem prática: o exame é 100% prático. Se você não consegue configurar SELinux ou LVM de cabeça num terminal, não está pronto.
  • Pagar pelo RHEL para praticar: use Rocky Linux ou AlmaLinux — são clones binários gratuitos. O ambiente de exame usa RHEL, mas os comandos são idênticos.
  • Ignorar SELinux: é um dos tópicos mais cobrados e mais evitados. Domine setenforce, chcon, restorecon e setsebool.

LFCS: Linux Foundation Certified SysAdmin

📖 Explicação

O LFCS (Linux Foundation Certified SysAdmin) é um exame prático de 2 horas em sistema live, vendor-neutral. Cobre conceitos gerais de administração Linux sem focar em uma distro específica.

  • Formato prático, similar à RHCSA mas em sistema genérico (Ubuntu ou CentOS).
  • Menos reconhecida que RHCSA no mercado, mas mais acessível e útil para demonstrar competências gerais.
  • Boa opção para quem trabalha com distros não-Red Hat e quer uma certificação prática.
  • A Linux Foundation também oferece LFCE (Engineer) como próximo nível.

Roadmap: Linux → Cloud → DevOps/SRE

📖 Explicação

Linux é a base de toda a stack moderna. Cada camada constrói sobre a anterior — pular etapas causa lacunas que se manifestam nos piores momentos (incidentes de produção).

ℹ️ Distros recomendadas por objetivo
  • Iniciante: Ubuntu LTS — estabilidade, enorme comunidade, PPA para softwares extras, excelente documentação. Escolha se quer usar Linux, não aprender seus internos.
  • Desenvolvedor: Fedora — tecnologia de ponta (kernel recente, Wayland, Pipewire), patrocinado pela Red Hat, DNF rápido. Ideal para desenvolvimento de software moderno.
  • Aprender a fundo: Arch Linux — você instala tudo manualmente, aprende cada decisão. A Arch Wiki é o melhor recurso de documentação Linux existente. Escolha se quer entender, não apenas usar.
  • Servidor estável: Debian — ciclos de release longos, extremamente estável, sem patrocinador corporativo. Ideal para servidores que precisam de anos sem quebrar.
  • Ambiente Red Hat: Rocky Linux ou AlmaLinux — clones gratuitos do RHEL para quem quer o ambiente RHEL sem pagar licença.
  • Containers/Minimalismo: Alpine Linux — imagem base de ~5MB, usa musl libc, mínima superfície de ataque. Padrão em imagens Docker de produção.

Próximos passos práticos

📖 Explicação

O estudo teórico só consolida quando combinado com prática real. Aqui estão passos concretos para aplicar tudo que você aprendeu neste módulo e nos anteriores.

⚡ Ações concretas para esta semana
  • Monte um laboratório: VirtualBox ou WSL2 com Ubuntu LTS para prática diária
  • Configure um servidor web (nginx) do zero num servidor VPS (DigitalOcean, Linode — a partir de $5/mês)
  • Escreva um script de backup e configure-o no cron (crontab -e)
  • Pratique os comandos de rede: ss, dig, curl -v, tunel SSH
  • Para RHCSA: instale Rocky Linux numa VM e pratique LVM, SELinux e systemd
  • Leia a Arch Wiki — mesmo sem usar Arch, é a melhor referência de conceitos Linux
💡 Analogia — Aprender Linux é como aprender a cozinhar

Você pode assistir todos os vídeos de culinária do mundo, mas a habilidade só vem cozinhando. Cada comando que você digita, cada erro que você depura, cada servidor que você configura — isso é o que forma o conhecimento real. Os módulos do LinuxWiki são a receita; o terminal é a cozinha.

ℹ️ Recursos para continuar
  • Arch Wiki (wiki.archlinux.org) — referência técnica de alta qualidade para qualquer distro
  • man pages — man comando e man -k palavra-chave diretamente no terminal
  • explainshell.com — explica cada parte de um comando shell
  • overthewire.org/wargames/bandit — aprenda Linux na prática através de desafios de segurança
  • linuxupskillchallenge.org — curso gratuito de administração de servidores Linux em 20 dias
